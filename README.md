# CV Builder

A modern, editable CV/Resume builder with PDF export.

## Features
- ✨ Live editing - click any text to edit
- 📄 Professional PDF export
- 🎨 Clean, minimal design
- 📱 Responsive layout
- 🎓 Guided tutorial for new users

## Tech Stack
- React (Create React App)
- Pure CSS (no framework)
- Lucide Icons
- Vercel Serverless Functions (PDF generation)

## Local Development

```bash
npm install
npm start
```

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/cv-builder)

1. Push to GitHub
2. Import to Vercel
3. Deploy!
